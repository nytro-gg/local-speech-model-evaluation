# Experimental Evidence

This directory contains selected screenshots from the earlier setup and model experiments. They provide supporting evidence of transcription attempts, language detection, code, Parakeet memory behavior, audio processing and CLI setup.

| File | Evidence |
|---|---|
| `01_faster_whisper_success.png` | Earlier Faster-Whisper successful transcription |
| `02_language_detection_en.png` | Earlier English language detection output |
| `03_transcribe_py.png` | Python transcription implementation |
| `04_parakeet_memory_failure.png` | Parakeet CPU memory-allocation failure |
| `05_audio_processing_details.png` | Audio processing and conversion details |
| `06_parakeet_cli.png` | Parakeet CLI/model setup |

**Scope note:** These screenshots are historical evidence. They are not terminal screenshots of the matched November 2026 Small/Medium runs; those measurements are documented in the benchmark result files. Private audio, raw private transcripts and per-run local metadata are intentionally not published.
